# The Golden Platter — ASP.NET Restaurant Website

An academic web development project created using ASP.NET Web Forms and C# as part of my BSc (Honours) in Computing at Dublin Business School.

## Project Overview

The Golden Platter is a restaurant-themed website developed to practise web application development using ASP.NET Web Forms.

The project includes multiple website pages and supporting C# code-behind files, demonstrating how page layouts and server-side application logic can be organised in a .NET web project.

## Technologies Used

- ASP.NET Web Forms
- C#
- HTML and CSS
- Visual Studio
- .NET Framework

## Project Components

- `.aspx` files — Website pages
- `.aspx.cs` files — C# code-behind
- `Site.Master` — Shared website layout
- `Staff.aspx` — Staff-related page
- `TheGoldenPlatter.sln` — Visual Studio solution
- `TheGoldenPlatter.csproj` — Project configuration
- `Web.config` — Application configuration

## Skills Demonstrated

- ASP.NET Web Forms development
- C# programming
- Website structure and page layout
- Working with code-behind files
- Master pages and reusable layouts
- Web application project organisation

## How to Open the Project

1. Open the solution file `TheGoldenPlatter.sln` in a compatible version of Visual Studio on Windows.
2. Restore any required NuGet packages.
3. Check the .NET Framework and IIS Express requirements.
4. Build and run the application locally.

## Project Status

Academic web development project. This repository contains the source files and project configuration. A live deployment is not provided.
